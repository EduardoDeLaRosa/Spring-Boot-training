# Solution — Proyecto 3

Implementación completa de referencia del Proyecto 3.

La solución mantiene deliberadamente el nivel del Módulo 1:

- entidad utilizada como modelo HTTP y JPA;
- mapeo manual de campos durante `PUT`;
- Query Methods en Spring Data JPA;
- reglas temporales en el Service;
- excepciones globales;
- auditoría automática.

No se han introducido DTOs, MapStruct, relaciones JPA, Specifications ni testing porque pertenecen a fases posteriores de la serie.
