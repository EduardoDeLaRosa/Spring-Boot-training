# Working

Esta carpeta contiene la base desde la que debes implementar el Proyecto 1.

El proyecto ya incluye:

- configuración Maven,
- Java 21,
- Spring Boot,
- Spring Web MVC,
- Spring Data JPA,
- Bean Validation,
- H2,
- clase principal,
- configuración local de base de datos.

Debes crear tú las capas y clases indicadas en el `README.md` de la raíz.

## Orden recomendado

1. `model`
2. `repository`
3. `service`
4. `exception`
5. `controller`
6. auditoría
7. pruebas manuales con Postman

No necesitas `CommandLineRunner`.
